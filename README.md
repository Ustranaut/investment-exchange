
# InvestSim — биржа инвестиционных пакетов

Учебный веб-симулятор с каталогом инвестиционных пакетов, регистрацией пользователей, корзиной и оформлением заказов.

https://legendary-space-eureka-q77vwvr79r773v6w-5000.app.github.dev/
## Возможности

### Каталог пакетов
- Просмотр активных пакетов.
- Поиск по названию и описанию.
- Подробная информация о каждом пакете.
- Цена в российских рублях (₽).
- Срок, условная доходность и доступный лимит.

### Пользователи
- Регистрация и авторизация.
- Личный аккаунт.
- Роли: клиент, менеджер, супер-администратор.
- Разграничение доступа.

### Корзина и заказы
- Добавление пакетов в корзину.
- Изменение количества и удаление товаров.
- Автоматический расчёт общей стоимости.
- Проверка доступного количества пакетов.
- Оформление учебного заказа.
- История заказов пользователя.
- Номер и статус заказа.

### Административная панель
- Управление пользователями и ролями.
- Создание и редактирование пакетов.
- Управление заказами и их статусами.
- Управление акциями и промокодами.
- Управление демонстрационными котировками.
- Просмотр журнала действий.

## Запуск в GitHub Codespaces

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Применение миграций:

```bash
python manage.py migrate
```

Добавление демонстрационных пакетов:

```bash
python manage.py seed_demo
```

Запуск приложения:

```bash
python manage.py runserver 0.0.0.0:5000
```

Для подключения PostgreSQL используется переменная окружения `DATABASE_URL`.
